# StudyLens：有出处的课程笔记问答

根据用户上传的 TXT、Markdown、JPG/PNG、PDF 或 DOCX 笔记检索原文，生成带引用的回答。图片和 PDF 扫描页通过本地 OCR 转成文字。


## 功能
图片与扫描 PDF OCR、DOCX/PDF 文字提取、文件分段、字符 TF-IDF 检索、基于证据的 AI 回答、引用编号检查、反馈导出。

文件上传后请先展开“检查文档提取结果”。印刷体通常更容易识别；手写体、复杂 PDF 排版和公式可能提取错误，重要内容应与原文件核对。加密 PDF、旧版 `.doc` 暂不支持。

## 运行
Python 3.10+；安装 requirements.txt 后执行 python -m streamlit run app.py。
页面默认显示“上传自己的笔记”；也可以在“笔记来源”中选择内置示例。AI 模式在网页左侧栏填写用户自己的 API Key、接口地址和模型名称，配置仅用于当前会话。
